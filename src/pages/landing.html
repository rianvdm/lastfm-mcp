Ask your AI about everything you've ever listened to.

Connect your Last.fm history to Claude, ChatGPT, or another supported app. Ask when you first played an album, what you had on repeat last summer, or what to play next.

Set it up Free, open source, read-only

Things you can ask

Ask in your own words. It reads your scrobbles, charts, and loved tracks, and works out days like "yesterday" in your own timezone.

  • When did I start listening to Radiohead?
  • What was I obsessed with last summer?
  • How has my taste changed since 2015?
  • What did I listen to yesterday?
  • Find me artists like my top five, but ones I've never played
  • Where should I start with Talk Talk, given what I already like?
  • Which albums did I play to death and then forget about?

Set it up

Pick the app you use. Either way, you'll sign in to Last.fm once at the end.

Claude app

Using Claude Team or Enterprise? An Owner needs to add Last.fm under Organization settings → Connectors. You can then click Connect and sign in. For a personal account, follow these steps.

  1. Open Claude (desktop app or claude.ai) and go to Customize → Connectors
  2. Click Add, then Add custom connector. Name it Last.fm, paste this address, and click Continue: 
    {{ORIGIN}}/mcp
  3. Leave the sign-in settings as they are and click Add, then Connect, and sign in to Last.fm
  4. Start a new chat and ask something

On the Free plan you can add one custom connector.

Claude Code or another agent

Paste this into your agent to set up the connection. It will tell you how to sign in.

Set up the Last.fm MCP server for me. Instructions are at {{ORIGIN}}/llms.txt

Or do it yourself

Using Claude Code? Run this in your terminal:

claude mcp add --scope user --transport http lastfm {{ORIGIN}}/mcp

Start Claude Code, run /mcp, choose lastfm, then Authenticate, and sign in to Last.fm in your browser.

Other apps

Choose your app below for setup and sign-in instructions.

ChatGPTBusiness, Enterprise, and Edu

Works on ChatGPT Business, Enterprise, and Edu, on the web. A workspace admin or owner adds it once; after your admin gives you access, you install it and sign in. OpenAI's guide has the details.

For a workspace admin or owner

  1. Open ChatGPT on the web and go to Plugins (chatgpt.com/plugins)
  2. Click +, then Add custom MCP server
  3. Name it Last.fm and paste this as the Server URL: 
    {{ORIGIN}}/mcp
  4. Choose OAuth for authentication, read the warning, then click I understand and want to continue and Create as a plugin
  5. Publish it to your workspace

Once your admin gives you access

  1. In ChatGPT on the web, open Plugins, find Last.fm and install it
  2. Sign in to Last.fm when ChatGPT asks
  3. In a chat, type @ and pick Last.fm
Cursor~/.cursor/mcp.json

Open or create ~/.cursor/mcp.json in a text editor. ~ means your home folder. If the file already has an mcpServers section, add only the lastfm entry inside it and keep your other settings. 

{
  "mcpServers": {
    "lastfm": {
      "url": "{{ORIGIN}}/mcp"
    }
  }
}

Cursor then asks you to sign in to Last.fm.

Devin Desktop (formerly Windsurf)mcp_config.json

Open or create ~/.config/devin/mcp_config.json in a text editor. ~ means your home folder. If the file already has an mcpServers section, add only the lastfm entry inside it and keep your other settings. 

{
  "mcpServers": {
    "lastfm": {
      "url": "{{ORIGIN}}/mcp"
    }
  }
}

Then run devin mcp login lastfm and sign in to Last.fm.

OpenCodeopencode.json

Open or create opencode.json in a text editor. If the file already has an mcp section, add only the lastfm entry inside it and keep your other settings. 

{
  "mcp": {
    "lastfm": {
      "type": "remote",
      "url": "{{ORIGIN}}/mcp"
    }
  }
}

Then run opencode mcp auth lastfm and sign in to Last.fm.

Codex~/.codex/config.toml

Open or create ~/.codex/config.toml in a text editor (~ means your home folder). Add the section below. If mcp_servers.lastfm already exists, edit that section instead of adding it twice. 

[mcp_servers.lastfm]
url = "{{ORIGIN}}/mcp"

Then run codex mcp login lastfm and sign in to Last.fm in your browser.

Other apps that run MCP tools on your computervia mcp-remote

This option runs a helper called mcp-remote on your computer. Your app must support starting an MCP server with a command, and npx must be available. If your app uses an mcpServers JSON config, add the entry below to that file and keep your existing entries. Your browser opens for Last.fm sign-in when it first connects. 

{
  "mcpServers": {
    "lastfm": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ORIGIN}}/mcp"]
    }
  }
}

If your app has separate fields instead, enter npx as the command and -y, mcp-remote, and {{ORIGIN}}/mcp as its arguments.

What you're agreeing to

It only reads

It can look at your listening history. It can't scrobble, love tracks, or change anything on your account.

You sign in on Last.fm

You sign in on Last.fm's own page, so this site never receives your password. You'll need to sign in again after 30 days.

Open source

Every line is on GitHub. The privacy page spells out exactly what's stored and for how long.
